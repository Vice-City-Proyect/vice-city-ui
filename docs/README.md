# Documentación Frontend - Vice City Iguana Club

## Archivos generados

| Archivo | Propósito |
|---|---|
| `DESIGN-SYSTEM.md` | Sistema de diseño de la landing: tokens, tipografía, botones, cards, secciones, responsive y convenciones visuales |
| `FRONTEND-GUIDE.md` | Guía completa: arquitectura, componentes, datos, patrones |
| `FRONTEND-QUICKSTART.md` | Guía rápida para desarrollo y agregar código |
| `FRONTEND-MAP.md` | Mapa visual del árbol de componentes y flujo |
| `COMPONENTS-API.md` | Referencia rápida de props/APIs de componentes |

## Interfaces de la aplicación (por rol)

Documentación de las 12 interfaces construidas con datos mock (sin backend):

| Archivo | Propósito |
|---|---|
| `APP-CORE.md` | Base compartida: mapa de rutas, tipos, `lib` (reglas de negocio), componentes UI, layout, datos mock y verificación |
| `ADMIN-INTERFACES.md` | 5 interfaces de administración: `/admin`, reservas, servicios, usuarios y ganancias |
| `CLIENTE-INTERFACES.md` | 3 interfaces de cliente: inicio, mis reservas y mi perfil |
| `EMPLEADO-INTERFACES.md` | 4 interfaces de empleado: panel, reservas/acceso, punto de venta y validación QR |

## Recomendación

Leer `DESIGN-SYSTEM.md` primero para entender qué diseño usamos y cómo mantenerlo consistente,
luego `FRONTEND-GUIDE.md` para entender el proyecto, y usar los demás como referencia. Para las
interfaces por rol, empezar por `APP-CORE.md` y luego el documento del rol correspondiente.
